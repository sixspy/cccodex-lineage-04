## 下线命运

节点下线时必须在同一事务里选一种命运，落定后不可改写：

- **影子草稿**：悬挂边被影子草稿表收纳并移出活边表，影响分析禁止读取（影响页剔除）。
- **旁路账册**：悬挂边留在活边表，指纹写入独立凭证行，影响分析仍可见。

同一节点只留一条命运行；同一悬挂边只落一种命运（两端节点先后下线也不会二次改写）。并发点同一节点由 `BEGIN IMMEDIATE` 串行化，后到者收到 409 中文说明，绝不覆盖前一名值班的命运。目录指纹随节点 / 边 / 影子 / 旁路 / 命运行任一变化而变，清洗入库指纹不一致即拦下。
